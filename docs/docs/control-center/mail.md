Sends mail to the account selected in the top bar, and lists what is already in its mailbox.

Mail is often the better way to hand something over than a direct grant: the client processes the attachment through the same path it uses for real rewards, so first-time-acquisition side effects fire properly.

## Composing

- **Sender** and **Comment** are free text. They default to Plana and a line about the management team.
- **Expires in** is a number of days.
- **Attachments** are built one at a time from a picker. Four kinds are supported:

| Kind | Amount |
| --- | --- |
| Item | yes |
| Currency | yes |
| Equipment | yes |
| Character | no - one row per character |

Characters sent by mail arrive at the star grade the game data says they should default to.

## The mailbox

Below the composer is what the account currently has, newest first, with the send date and whether it has been claimed. Mail can be deleted from here.

The client's mailbox view is windowed, so a very large mailbox does not all show up at once in game even though it is all listed here.
